# MHI Nova Link Wiki

Welcome to the documentation for the **MHI Nova Link** Home Assistant custom integration.

This integration connects Home Assistant to a **CompTrol 4Web NOVA RC** gateway and exposes climate controls, airflow controls, diagnostics, and gateway status.

## Who this is for

Use this integration if you have Mitsubishi Heavy Industries HVAC units managed by a CompTrol 4Web NOVA RC on your local network.

## What you get

- Zone climate entities (mode, target temperature, fan mode, swing mode)
- Zone airflow controls (louver and vane position)
- Zone and indoor-unit diagnostics
- Gateway status and update-availability sensors
- Automatic TLS fingerprint pinning for self-signed certificates
